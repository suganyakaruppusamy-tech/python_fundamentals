# 🐍 Python Fundamentals Case Study

## 📌 Project Overview
This repository documents my journey of learning **Python fundamentals** through practical case studies.  
Each section demonstrates how core Python concepts can be applied to solve real-world problems, from string manipulation to data structures and error handling.

---

## 🎯 Objectives
- Strengthen understanding of Python basics through hands-on examples.
- Apply concepts like variables, loops, conditionals, and functions in case studies.
- Explore data structures (lists, tuples, dictionaries, sets) with practical use cases.
- Practice debugging and error handling.
- Build confidence for advanced topics like Pandas, NumPy, and visualization libraries.

---

## 🛠 Tools & Environment
- **Python 3.x**
- **Google Colab / Jupyter Notebook**
- Standard Python libraries (no external dependencies for fundamentals)

---

## 📂 Case Studies & Learnings

### 1️⃣ Variables & Data Types
- Declaring integers, floats, strings, and booleans.
- Type conversion and basic operations.

### 2️⃣ String Operations
- Slicing, indexing, concatenation.
- Methods like `.replace()`, `.split()`, `.upper()`, `.lower()`.

### 3️⃣ Control Flow
- `if-else` statements for decision making.
- Nested conditions and logical operators.

### 4️⃣ Loops
- `for` and `while` loops.
- Iterating over lists, ranges, and strings.

### 5️⃣ Functions
- Defining reusable functions.
- Parameters, return values, and scope.

### 6️⃣ Data Structures
- **Lists**: append, extend, slicing.
- **Tuples**: immutability and unpacking.
- **Dictionaries**: key-value storage, `.get()`, `.items()`.
- **Sets**: uniqueness, union, intersection.

### 7️⃣ Error Handling
- `try-except` blocks.
- Handling `NameError`, `ValueError`, and custom exceptions.

### 8️⃣ Practical Mini-Projects
- Text cleaning with string methods.
- Basic calculator using functions.
- Frequency counter using dictionaries.
- Simple menu-driven program with loops and conditionals.

---

## 🔑 Skills Learned
- Python syntax and structure
- String manipulation
- Control flow and iteration
- Functions and modular programming
- Working with lists, tuples, dictionaries, and sets
- Debugging and error handling
- Writing clean, reusable code
